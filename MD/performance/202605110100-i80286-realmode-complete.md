## State register 新增

Sprint 27.1-27.3 對 i80286 的 register_file 加了這些 slot：

| Register | Width | Reset | Sprint |
|---|---|---|---|
| MSW         | 16 | 0xFFF0 | 27.1 |
| GDTR_LIMIT  | 16 | 0      | 27.2 |
| GDTR_BASE   | 32 | 0      | 27.2 |
| IDTR_LIMIT  | 16 | 0      | 27.2 |
| IDTR_BASE   | 32 | 0      | 27.2 |
| LDTR        | 16 | 0      | 27.3 |
| TR          | 16 | 0      | 27.3 |

總共 5 個新 16-bit + 2 個新 32-bit slot = 18 byte 加到 i80286 CPU state。
