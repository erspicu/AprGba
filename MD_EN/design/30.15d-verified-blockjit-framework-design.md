# Phase 30.15d — Verified Block-JIT framework

> **Status**: ✅ **DESIGN + IMPL COMPLETE — 1M blocks NoDiff on real
> BIOS workload** (2026-05-17). Full design with 12 sections + 8-sprint
> implementation plan lives in the Chinese counterpart
> [`MD/design/30.15d-verified-blockjit-framework-design.md`](../../MD/design/30.15d-verified-blockjit-framework-design.md);
> this file is a brief English mirror.

## Goal

Catch JIT-emitter regressions the moment they happen rather than weeks
later through obscure boot failures. For every cached JIT block, run
the JIT once, restore pre-block state to a parallel INTERP env, run
the interpreter the same number of architectural instructions, then
3-axis compare: CPU state + memory-write trace + side-effect log.

## Core interfaces (`AprCpu.Core/Validation/`)

- `IBlockBoundedSteppableCpu` — opt-in extension of `ISteppableCpu`
  for CPUs that can be driven block-by-block under the verifier.
- `IBlockTraceSink` — per-block side-effect recorder
  (`RecordMemWrite`, `RecordPortWrite`, `RecordIrqAssert`).
- `RingBufferTraceSink` — fixed-capacity in-memory implementation.
- `VerifiedBlockJitRunner` — generic 7-step driver:
  snapshot → JIT block + trace → restore → INTERP × N + trace →
  3-axis compare → report first divergence with full context.

## Result

Three real x86 block-JIT bugs found and fixed during framework
bring-up:

1. **Phase 30.15b** — PC pre-write linear-vs-IP confusion (CS<<4 was
   being stored into the IP slot for low-CS segments)
2. **Phase 30.15c-B** — packed-tail `ImmConsumed` leak across switch
   arms in `X86ModRmComputeEaEmitter`
3. **Phase 30.15c-C** — INT n must push FLAGS with reserved bit 1 = 1
   per Intel spec

After all three fixes + verifier-framework correctness fixes (sprints
5.4b/5.4c/5.4d):

```
running verified-block up to 1,000,000 blocks...
  elapsed:         00:02:54
  verified blocks: 1,000,000
  verified instrs: 4,382,198
  status:          NoDiff
```

X86-16 block-JIT is bit-identical to per-instr for 4.38M consecutive
architectural instructions of real `pcxtbios.bin` + FreeDOS boot path.

### Sprint 5.5 + 5.6 — extended to GB + NES

Same framework + per-CPU adapter (~200 LoC) covers two more ISAs:

| CPU | Blocks verified | Architectural instructions | Runtime |
|---|---|---|---|
| x86-16 (i8086) | 1,000,000 NoDiff | 4,382,198 | 2:54 |
| LR35902 (GB)   | 278,872 NoDiff   | 1,484,292 | 4.6s (limited by JIT-vs-interp IRQ-delivery boundary asymmetry) |
| Ricoh 2A03 (NES) | 1,000,000 NoDiff | 2,002,097 | 6.2s |
| ARM7TDMI (GBA) | 1,000,000 NoDiff | 1,000,000 | 1:06 |

Demonstrates that the generic `IBlockBoundedSteppableCpu` interface +
`VerifiedBlockJitRunner` work across all 4 framework-target ISAs with
different word size (8/16/32-bit), register file, addressing modes,
and bus shape. Differential fuzzing (sprint 5.7) deferred.
