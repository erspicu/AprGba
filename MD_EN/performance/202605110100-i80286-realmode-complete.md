## Inheritance ROI continues to hold

i80286 spec total size at end of Phase 27a:
- `cpu.json`: ~110 lines (extending 80186, adding 7 new state registers)
- `groups/twobyteesc.json`: ~150 lines (4 dispatch groups + 2 standalone)
- Total: **~260 lines** of i80286-specific spec

Vs writing i80286 from scratch: ~3500 lines (8086 base + 80186 additions
+ 80286 system insts + register file + dispatch infra).

**Saving: ~93%** at this point in the chain. Each subsequent CPU spec
(80386, 80486, etc.) gets even more leverage from the chain.
